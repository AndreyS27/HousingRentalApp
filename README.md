# Веб-приложение для краткосрочной аренды жилья

Полнофункциональная платформа для аренды жилья, аналогичная по функционалу Airbnb.  
Разработана как дипломный проект для отработки навыков fullstack веб-разработки на .NET 8, PostgreSQL, Entity Framework Core и React с TypeScript.

### Используемые технологии (Backend)

| <!-- --> | <!-- --> |
| ------------|---------- |
Платформа | .NET 8
Фреймворк | ASP.NET Core 8
ORM	| Entity Framework Core 8
База данных | PostgreSQL 17
Аутентификация | JWT (JSON Web Tokens)
API | RESTful API с Swagger (OpenAPI)
Хранилище | Amazon S3 (Timeweb Cloud S3)
Архитектура | Трёхуровневая (Controllers → Services → Repositories)

### Используемые технологии (Frontend)
| <!-- --> | <!-- --> |
| ------------|---------- |
Библиотека | React 18
Язык | TypeScript 5
Стейт-менеджмент	| Redux Toolkit
Маршрутизация |	React Router DOM v6
UI-библиотека |	Mantine 7
Карты |	Яндекс.Карты v3 (ymap3-components)
HTTP-клиент |	Axios

## Технические особенности
- 🛡️ JWT-аутентификация — безопасная авторизация пользователей

- 📦 S3-хранилище — облачное хранение фотографий в Timeweb Cloud S3

- 🔄 CI/CD — автоматический деплой на Timeweb Cloud

- 📱 Адаптивный интерфейс — работает на любых устройствах

- 🗺️ Яндекс.Карты v3 — интерактивные карты с маркерами



## 🚀 Возможности
### Для всех пользователей
- 🔍 Поиск объектов — поиск жилья по городу, датам и количеству гостей

- 🗺️ Интерактивная карта — визуализация объектов на Яндекс.Картах

- 📋 Фильтрация — по цене, типу жилья, количеству комнат и удобствам

- 🖼️ Фотогалерея — просмотр фотографий объектов в карусели и модальном окне

- 📊 Рейтинги и отзывы — просмотр оценок и отзывов других пользователей


### Для арендаторов
- 📝 Регистрация и авторизация — через email с JWT-токенами

- 👤 Личный кабинет — управление профилем (имя, фамилия, телефон, аватар)

- 📅 Бронирование — создание бронирований с выбором дат и оплатой

- 💳 Имитация оплаты — тестовый платёжный шлюз для демонстрации

- 📜 История бронирований — просмотр всех своих бронирований

- ⭐ Отзывы — оставление, редактирование и удаление отзывов

### Для арендодателей
- 🏠 Управление объектами — добавление, редактирование и удаление объявлений

- 📸 Загрузка фото — до 9 фотографий на объект с хранением в S3

- 📊 Статистика — просмотр количества просмотров объявлений

- 💰 Управление бронированиями — подтверждение или отклонение заявок

- 📈 Доход — отображение общего дохода от сдачи жилья

- 🗓️ Управление датами — блокировка дат и переопределение цен
